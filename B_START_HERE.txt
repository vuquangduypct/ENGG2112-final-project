START ON ANOTHER WINDOWS COMPUTER
1. Obtain authorised access to the APTOS competition and accept its rules:
   https://www.kaggle.com/competitions/aptos2019-blindness-detection/data
2. Extract the private archive into a new local folder. Open that folder in VS Code.
   Do not extract over another experiment's files.
3. In a terminal at the folder containing src and this file, run:
   py -3.12 -m venv .venv
   .\.venv\Scripts\python.exe -m pip install -r requirements.txt
   .\.venv\Scripts\python.exe -m src.handoff_data --verify
   .\.venv\Scripts\python.exe -m examples.load_data_for_b
4. Verification should report 3,600 images: train 2,521; validation 538; test 541.
   The reading example should show (224, 224, 3), uint8, and a grade from 0 to 4.
5. Install the training framework required for your model separately. The supplied
   environment is for data work. requirements-lock.txt records A's tested Windows
   Python 3.12 environment; use it if exact reproduction is required and compatible.

DATA CONTRACT
Task: single-label five-class prediction. Keep grades 0, 1, 2, 3, 4 unchanged.
0 No DR; 1 Mild; 2 Moderate; 3 Severe; 4 Proliferative DR.
Inputs: PNG, RGB, 224x224, uint8 values 0..255. The helper returns HWC arrays.
Transformation: aspect-preserving LANCZOS resize and black padding.
Automatic black crop: OFF. Augmentation: NONE. Model normalization: NONE.
B must select the model and apply its required channel order, float conversion,
normalization, and training-only augmentation exactly once. A softmax classifier
would have five output scores; any alternative ordinal formulation needs agreement.

CANONICAL FILES
artifacts/splits/split_manifest.csv: id_code, diagnosis, split, group_id, pixel_sha256.
data/processed_224_v1/processed_manifest.csv: id_code, diagnosis, split, relative_path,
crop_box. Join by id_code, never by directory listing order.
data/processed_224_v1/preprocessing_config.json: transform and source manifest hash.
docs/handoff_contract.json: version, counts, assumptions and metadata fingerprints.
artifacts/handoff/image_checksums.csv: exact hashes of the prepared PNG files.
src/handoff_data.py: validation and framework-independent image-reading interface.

KNOWN ISSUES AND EXCLUSIONS
Original dataset: 3,662 labelled images; all decoded successfully in the audit.
123 exact pixel duplicate groups contain 251 records. Of these, 30 groups have
conflicting grades and contain 62 records. These 62 are temporarily excluded,
not relabelled or deleted. Details: artifacts/splits/excluded_records.csv.
Same-grade exact duplicates stay together within one split but remain repeated
records. There are 3,504 exact-image groups among the 3,600 eligible records.
The similarity heuristic found 4,096 candidate pairs, not 4,096 confirmed duplicates.
No manual decisions have been added. Data contain no age or patient ID columns.
Do not claim patient independence, final absence of leakage, or elderly performance.
